# Composer

The draft area that opens in the panel, beside the passage, never in a pop-up over the text: category chips, a textarea, Cancel and Save.

The consumer provides the categories, the placeholder ("Your comment…" / "Votre commentaire…", or the reply variant) and the save/cancel handlers.

- Chips first, then the textarea (`paper` ground, `line-strong` border, focus ring `focus`).
- Show the shortcut as plain text in `ink-muted`: Ctrl+Enter saves, Esc cancels.
- Save is the only primary button in the panel.
