Open a note in Live Preview. A web article saved with the [Obsidian Web Clipper](https://obsidian.md/clipper) is a good place to start: the source text and your remarks will never get mixed up.

## Write the comment

Select a passage, or just place the cursor, then right-click and choose *Comment on selection* or *Comment here*. You can also run the command *Comment on selection or cursor* from the palette. For speed, give it a hotkey in *Settings → Hotkeys*; Ctrl+Alt+M, the Word shortcut, works well.

The draft opens in the *Comments* panel on the right, so the text stays visible. Pick a category if you want one (a coloured chip), write, then press Ctrl+Enter. Esc cancels.

## What happens in the note

The passage is now underlined in the category's colour. A comment placed at the cursor, with no selection, shows as a small bubble. Click either one to open its thread in the panel. The category's tag is added to the note's `tags` property, and removed when no comment of that category remains, unless you had set the tag yourself.

## Reply, edit, delete

Each thread in the panel offers *Reply*, *Edit* and *Delete*. Deleting a comment removes its markers and leaves the source text untouched. Ctrl+Z undoes.

## Find it again

Comments are text inside the note, so Obsidian's search finds them across the vault. Category tags work with `tag:#…`, the tags pane and Dataview.

The plugin works in Live Preview. In reading view the markers are hidden, but passages are not underlined. Threads have a single level of replies, and each comment has a single category.
