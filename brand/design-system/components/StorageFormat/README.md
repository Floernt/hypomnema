# StorageFormat

Code block for documentation of the plain-text format: `code` style in IBM Plex Mono on `paper-raised`.

The consumer provides the code text; wrap anchor markers (`%%[aN%%`, `%%aN]%%`) in `hy-mk` (rubric) and the block fences in `hy-dim` (`ink-muted`).

- Use it for the storage format, regexes, file paths (`<vault>/.obsidian/plugins/hypomnema/`) and commands.
- No syntax-highlighting theme beyond these two colours.
